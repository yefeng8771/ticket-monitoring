# v1.6.0 · 微信级扁平化重构与全站交互收口（2026-11-08）

本次是界面与交互的一次整体升级，不改变采集与解析口径。

## 检索台

- 顶部重排为「城市对 + 交换 + 日期 + 实时探针」主任务动线，去掉低信息量标签；
- 10 家渠道（5 浏览器 + 5 App）独立成行，图标 + 名称同源，窄档可横滑；
- 组合探针入口移到探针按钮下方，展开面板紧贴触发器，两态坐标不跳动；
- 筛选改为锚定浮层（桌面）/底部抽屉（移动），面板内部连续选择不关闭，
  只有「完成 / 关闭 / Esc / 点击面板外」才关闭；
- 同一时刻只允许一个临时浮层，浮层之间互斥，无残留遮罩与点击穿透。

## 渠道健康

- 诊断条、健康矩阵、节流与干预、溯源四块整体重排；
- 诊断、健康行、节流行、登录卡、检索、配置、推送、导出、演示站共用同一套
  10 渠道名单与中文名；
- 节流面板两栏布局，溯源改轻表格，URL 独占整行；去哪儿停服说明并入渠道行。

## 全站

- 统一控件高度、字号阶、圆角、间距与按钮多态文案；
- 明细筛选窄档改真抽屉，底部操作条贴底并预留末行让位；
- 320/390 搜索表单回绕、渠道图标档、输入框 16px 防 iOS 放大；
- 修复筛选面板内部点击即关闭、渠道浮层落到页底、展开收起挤压首行等交互缺陷。
